# Product Name Ideas (`ISIMLER.md`)

25 short, searchable, trademark-safe product names for our open-source cross-platform (Windows + Linux) AI subscription quota desktop widget.

## Naming Constraints Applied
- **Zero trademarked terms**: None of the names contain `Claude`, `OpenAI`, `Codex`, `Gemini`, `Nothing`, or `Copilot`.
- **Excluded known/taken names**: Avoids all listed taken names (`CodexBar`, `ccusage`, `TokenBar`, `Quosparr`, `Quorb`, `Clawdmeter`, `BrimDeck`, `Quota`, `onWatch`, `tidemark`, `AI-Usage`) as well as additional tools surfaced during our web searches (`ai-usagebar`, `TaskbarQuota`, `CodeQuota`, `AIQuotaBar`, `ai-gauge`, `OpenQuota`, `ai-pace`, `ai-meter`, `ai-quota`, `Pulse`).

---

## Top 5 Recommendations (★)

1. ★ **Pacebar** (`pacebar`) — Immediately communicates both the status-bar/widget form factor and the signature "time-elapsed pace vs. quota burn" concept.
2. ★ **Capdeck** (`capdeck`) — Short, punchy two-syllable name evoking a desktop control deck for subscription rate caps.
3. ★ **Quotik** (`quotik`) — Distinctive 6-letter coined word combining "quota" + "tick" (countdown clock tick); highly searchable on GitHub and package managers.
4. ★ **Rategauge** (`rategauge`) — Clear instrument-inspired name that fits radial rings, retro LCD, and dot-matrix telemetry themes equally well.
5. ★ **Pacedeck** (`pacedeck`) — Blends window-pacing telemetry with a docked desktop card/deck metaphor.
